# Senior Frontend Developer (React/Next.js)

**Company:** TechNova Solutions
**Location:** Remote (EMEA) / Istanbul
**Type:** Full-time

## Role Overview
We are seeking a highly skilled Frontend Developer with deep expertise in React and modern JavaScript ecosystems. You will architect and build scalable UI components.

## Key Responsibilities
* Lead the architecture and development of scalable frontend applications using React and Next.js.
* Optimize application performance for maximum speed and scalability across various devices and browsers.
* Manage state efficiently using tools like Redux, Zustand, or simple Context API patterns.
* Participate in agile ceremonies.

## Requirements
* 5+ years of professional experience in frontend development.
* Proven expertise in React.js and its core principles, including modern hooks.
* Strong experience with TypeScript in production environments.
* Solid understanding of state management (e.g., Redux Toolkit, React Query).
* Experience with CSS-in-JS libraries (Tailwind CSS, Styled Components).
* Experience with testing frameworks (Jest, React Testing Library, Cypress).
